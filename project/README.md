- **Краткое описание:**  
  Проект посвящён построению сервиса автоматической оценки рыночной стоимости подержанных автомобилей на основе их характеристик. ## 4. Как запустить проект

### 4.1. Скачать датасет

```bash
pip install kaggle

# Положить kaggle.json в ~/.kaggle/
# Скачать датасет:
kaggle datasets download -d austinreese/craigslist-carstrucks-data \
  --path data/raw/ --unzip
```

Файл `vehicles.csv` (~1.45 ГБ) появится в `data/raw/`.  

Если со скачиванием с kaggle проблемы, то можно разархивировать vehicles.7z в папку `data/raw/`.  

### 4.2. Обучение модели

```bash
# На сырых данных (занимает 2 минуты):
python -m src.train --model rf

# Доступные алгоритмы: xgboost | rf | ridge
```

Модель сохраняется в `artifacts/models/`.

### 4.3. Запуск сервиса через Docker (рекомендуется)

```bash
docker compose build
docker compose up -d

# Проверка:
curl http://localhost:8000/health
```

Сервис поднимается на **порту 8000**. Если в `artifacts/models/` уже лежит обученная модель — она подхватывается автоматически через примонтированный volume. Если модели нет — сервис обучается в demo-режиме на синтетических данных.

### 4.4. Запуск сервиса локально (без Docker)

```bash
source .venv/bin/activate
uvicorn src.service.app:app --host 0.0.0.0 --port 8000 --reload
```

### 4.5. Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/health` | Проверка работоспособности |
| `GET` | `/model/info` | Метрики и метаданные модели |
| `POST` | `/predict` | Предсказание цены одного автомобиля |
| `POST` | `/predict/batch` | Пакетное предсказание (до 100 авто) |

Интерактивная документация (Swagger UI): `http://localhost:8000/docs`

### 4.6. Пример запроса

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "manufacturer": "toyota",
    "condition": "good",
    "cylinders": "4 cylinders",
    "fuel": "gas",
    "odometer": 60000,
    "title_status": "clean",
    "transmission": "automatic",
    "drive": "fwd",
    "type": "sedan",
    "paint_color": "white",
    "state": "ca",
    "car_age": 5
  }'
```

Пример ответа:

```json
{
  "predicted_price": 17850.00,
  "ci_lower": 13200.00,
  "ci_upper": 23400.00,
  "confidence": 0.862,
  "model_used": "XGBoost",
  "latency_ms": 18.4
}
```

## 8. Ограничения и дальнейшая работа

Текущие ограничения:
- Датасет только американский (Craigslist, цены в USD, пробег в милях) — модель не применима к другим рынкам напрямую
- Датесет обновлялся последний раз в 2022, а значит будет проблема расхождения данных (distribution shift)
- Цены в данных — запрашиваемые, а не реальные цены сделок
- Гиперпараметры подобраны вручную, без автоматической оптимизации

В дальнейшем можно добавить:
- Автоподбор гиперпараметров через Optuna
- Мониторинг дрейфа входных данных
- Хранение истории запросов в БД
- Авторизацию через API-ключ
- Поддержку других рынков (добавить данные с европейских/российских площадок)
